# プレイヤーモーション統一・代表案レビュー

作業ブランチ: `codex/player-motion-unification`  
分岐元: 最新化したmain / `3257ea5`  
段階: **代表案の方向性了承・髪色と吊り下がり動作を修正中・ゲーム未組み込み**

## 開き方

[review.html](review.html) をブラウザーで開く。
上段に比較サイズ1倍の一覧、下段にIdleと選択ポーズの2倍・4倍・6倍表示を用意した。
背景切り替えとチャージの回転軸プレビューを操作できる。

- Idleは既存シート左端の128×128フレームをそのまま表示する。
- 代表案は走り、上昇、降下、斜め上発射、斜め下発射、持ち手と鉄球側の鎖を別の手で握るチャージ4ポーズ、ぶら下がり2ポーズ、中央の鎖登り4ポーズ。
- 生成原画PNGは無加工で保存し、比較画面だけ身長と足元を合わせる。
- **比較サイズ1倍は表示基準。生成PNGの原寸や確定済みのゲーム用解像度ではない。**
- 鉄球・鎖のプレビューには既存素材の無加工コピーを使用する。新たな鉄球・鎖は描かない。
- 回転軸プレビューは資料用。球の表示サイズ・回転速度は実ゲームの再現ではない。
- 最終ピクセル整形、パレット統一、全コマの支点合わせは代表案の承認後に行う。

## 追加で確定した表現方針

- 走り・ジャンプ・投げは、静止画だけでなく連続したSpriteアニメーションの品質を重視する。
- 髪と服は動きから遅れてついてきて、大きめに広がり、切り返しと収束まで見せる。
- 特に降下は、ツインテールとカーディガンが上向きに「バサッ」と開く大きなシルエットにする。
- チャージは片方の手で持ち手を普通に保持し、もう片方の手で鎖と鉄球の接続部に近い鎖を握る。その鉄球側の握り位置を軸に鉄球を回す。
- ユーザー提供図は回転軸だけの参考。人物、服装、カメラ角度、立ち方はコピーしない。
- チャージ中は持ち手を握る手と鉄球側の鎖を握る手を分け、両方の役割を保ちながら肩・腰・膝・髪・服で勢いを表現する。
- 実装では既存の鉄球オブジェクトと鎖を動かす。キャラクター画像に鉄球を焼き込まない。

## 今回の追加修正

- チャージの「根元」は柄の根元ではなく、鎖と鉄球の接続部に近い鎖。片方は柄を普通に握り、もう片方でその鎖を握って回す。以前の「片手で柄を軸にする」解釈は誤りとして破棄した。

- Idleの実画像から髪の基準色（主色#E08398、影#BD637E/#B35D78、深い影#551E31/#4A1728）を採取し、全代表案の髪色調整に指定した。生成画像の全画素が厳密に一致したという意味ではない。
- ぶら下がり2枚・背面からの鎖登り4枚を追加。登りの最初の案は手が肩側へ寄っていたため不採用。
- ユーザーの指摘に従い、登りの上側の握りを頭・体の中央へ移し、中央の同じ一本の鎖を上下の手で握る想定に修正した。
- 比較画面では既存の鎖画像を中央に重ね、上側の握りの中心と鎖のX位置を揃える。生産用フレームの下側の握り・手の交代・接続位置は、最終ドット整形とあわせて詰める。
- ぶら下がり／登りのループ再生ボタンを追加した。

## 今回確認する点

1. Idleと比べた顔つき、頭身、髪・服・靴の配色。
2. 現在の引きずり走りの雰囲気を維持しているか。
3. 降下の髪・服の広がり方が、ゲームとして見ごたえのある方向か。
4. 斜め発射の方向と体の連動、持ち手→もう片方の手で握る鉄球側の鎖→鉄球、というチャージの役割と経路。

衣装のボタン・髪留め・顔つきなどにまだ細部の差がある。
チャージは4枚の動作キー案で、握り位置と足元のピクセル単位の固定や、8コマの位相同期には未調整。
斜め下の棒の角度・接続点も実装用に整える工程が残る。
これらを採用済み・実装済みとは扱わない。

## 承認後の制作と実装

| 系統 | 内容 |
|---|---|
| 地上移動 | 引きずり走り8コマ。既存のポーズ・雰囲気を継承して描き直す |
| ジャンプ | 上昇2・頂点1・落下2・着地3コマ。髪・服の遅れと大きな広がり、着地時の収束 |
| チャージ | 持ち手と鉄球側の鎖を別の手で握る縦回し8コマ。既存鉄球の回転角と同期 |
| 発射 | 横・斜め上・上・斜め下・下を各3コマ。左右反転の8方向と地上／空中の脚差分 |
| 回収・張力 | 回収2・停止中の地上踏ん張り2・空中で引かれる姿勢2コマ |
| 吊り下がり | ぶら下がり2・鎖登り4コマ |

Idle、移動性能、連続した照準と弾道、鉄球のRigidbody設定は維持する。
【最新の修正が優先】通常の持ち手用HandAnchorはそのままにする。チャージ専用に、もう片方の手が握る鉄球側の鎖の位置を別の回転軸として持つ設計とする。
既存の回転処理で実際の鉄球を動かし、描画専用の鉄球や別の物理制御は追加しない。
チャージ中の鎖の表示経路は、持ち手の先端→鉄球側の鎖を握る手→既存鉄球とする。チャージ開始・解除・発射・回収・Respawn等の全終了経路で専用の軸と経路表示を解除し、既存の通常／発射状態へ戻す。
回転半径・速度は既存設定を初期値とし、任意の補正値で問題を隠さない。
張力の姿勢は既存の張力適用結果を読み取る。
既存Animator・ClipのGUID・パラメーター・保持時間を保ち、特殊動作は既存の表示処理内で扱う。
Scene／PrefabはUnity MCP経由で更新し、ユーザー調整値・未保存変更を保護する。
被弾・死亡・専用クリア演出は今回の対象外。
