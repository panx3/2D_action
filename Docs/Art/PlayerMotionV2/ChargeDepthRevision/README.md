# 投擲ポーズとチャージ中の前後関係

- 投擲は既存の3コマを再利用し、最後のコマを0.14秒追加で保持する。通常のシーケンス長0.18秒と合わせて約0.32秒。Animatorの切替フレームも最後のコマでつなぐ。鉄球が床へ当たって先に通常の物理状態へ戻っても、絵はこの時間まで保持する。
- チャージ中、柄から軸の手までの鎖はキャラクターより前に置く。軸の手から鉄球までの鎖と鉄球はキャラクターの直後ろに置く。鎖リンクとLineRendererの両方で、衝突補正後の経路を軸の手で分けている。
- Stage1・Stage2の装飾と競合しないよう、鉄球と奥側の鎖はキャラクターと同じSorting Layer／Orderを使い、画面に影響しないZ差0.01で直後ろに描画する。チャージ終了時に鉄球Spriteの元のLayer／Order／Zを復元する。ColliderとRigidbodyの位置・物理設定は変更しない。
- 追加のSprite、Animatorパラメーター、Inspector項目はない。Idleとぶら下がりの素材は変更していない。

Stage1・Stage2でゲームパッド入力による走行・跳躍・チャージ・発射を確認。8回転位相、左右・地上空中、鎖リンク／線のみの両表示、チャージ解除・発射・Respawn時の復帰、下投げが床に即衝突する場合を確認した。Unityのコンパイル後、関連Error／Exceptionは検出されなかった。

`Stage1/Stage1-charge-charge.png` は木と鉄球が重なるゲーム画面、`Stage2-charge-phase-*.png` はStage2の回転位相ごとのゲーム画面。`*-validation.txt` と `*-trace.csv` は検証記録。
