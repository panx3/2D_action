# エディターの完全フルスクリーン Game ビュー

Windows / Unity 6000.4.2f1 用。追加パッケージやゲーム側の設定は不要です。

## 操作

1. Unity エディターでゲームを再生します。
2. Unity にフォーカスがある状態で **F11** を押します。
3. もう一度 **F11** を押すと元のエディターに戻ります。

`Tools > Tekkyu > Fullscreen Game View (F11)` からも切り替えられます。
キーの長押しによる連続切り替えは行いません。エディターの一時停止中にも使えます。
キーボードでの切り替えは F11 のみです。Esc はゲーム内の既存操作を維持し、
フルスクリーン解除や Editor 側のカーソル非表示解除には使いません。再生停止時は自動解除します。
フルスクリーン内では余白や一時停止中も Windows の標準カーソルを隠し、
ゲーム独自のカーソルは従来どおり表示します。

フルスクリーンを開く直前の Unity ウィンドウがあるモニターを使います。
元の Game ビューの解像度・アスペクト比の選択と Target Display を引き継ぎます。
固定解像度は比率を保って画面に収め、余った部分は余白になります。
Free Aspect の場合はモニターの比率を使用します。
高 DPI のアスペクト比モードでは低解像度表示を無効にし、モニターのピクセル数で表示します。
元の Game ビューの設定は変更しません。

## 実装・互換性

`Assets/Editor/FullscreenGameView.cs` だけで動作する Editor 専用拡張です。
標準 Game ビューを一時的な独立ウィンドウとして作り、Win32 で枠を取り除き、
モニターの全領域 (`rcMonitor`) に配置します。フォーカス中はタスクバーより前面に表示します。
ホストは `ShowWithMode(NormalWindow)` で作り、タブを持たせません。
Utility 形式にはネイティブの Esc でウィンドウを閉じる経路があるため使用しません。
Alt+Tab で別アプリに移ったときは最前面を解除します。
フルスクリーンのウィンドウ内だけで `WM_SETCURSOR` を処理し、標準カーソルを非表示にします。
Unity の `Cursor.visible` / `Cursor.lockState` や OS の `ShowCursor` カウンターは変更しません。
Esc の Editor イベントだけを UI Toolkit で止め、Input System のデバイス入力は維持します。
Windows のタスクバー自体や解像度設定を変更しないため、解除後のシェル復元は不要です。

元のタブやウィンドウを移動・最大化せず、一時ビューを閉じて元のフォーカスへ戻します。
一時ウィンドウはレイアウト保存対象から除外し、再生停止・スクリプト再読み込み・
エディター終了要求時に閉じます。Scene / Prefab を保存する処理はありません。
カメラ、Canvas、Input Actions、Time.timeScale、ランタイムの Screen 設定は変更しません。

Unity の公開 API は標準 Game ビューやそのツールバー設定を公開していないため、
該当箇所だけ reflection を使っています。必要な内部メンバーを開く前に確認し、
非互換やネイティブ操作失敗の場合は一時ウィンドウを閉じ、Console に警告を出します。
Unity 更新時は以下の動作確認を再実施してください。

参照: [Unity 6000.4 GameView](https://github.com/Unity-Technologies/UnityCsReference/blob/6000.4/Editor/Mono/GameView/GameView.cs)、
[Win32 SetWindowPos](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowpos)。

## 手動確認

- 再生中に F11 を押し、タスクバー、タイトル、メニュー、Game ビューのツールバーが見えないこと。
- F11 長押しで切り替えが繰り返されず、離して押し直すと解除できること。
- 16:9 / 固定解像度 / Free Aspect を切り替え、拡大時に縦横比や HUD が崩れないこと。
- Esc でゲーム内のポーズ等が動き、フルスクリーン解除や標準カーソルの再表示が起きないこと。
- マウス・ゲームパッド操作とゲーム独自のカーソルが従来どおり動くこと。
- 画面の余白や一時停止中も標準カーソルが出ず、解除後は Editor 内で通常どおり使えること。
- F11 解除後に元のタブ、ウィンドウ配置、Game ビュー設定へ戻ること。
- 一時停止中の F11、フルスクリーン中の再生停止でも正常に復元すること。
- Alt+Tab の移動先を覆わず、Unity に戻ると再び全面表示されること。
- 各モニター / DPI 設定で端まで表示されること。
- フルスクリーン中に Unity を終了し、再起動後に一時ビューが残っていないこと。

Windows の枠なし全面表示です。排他的フルスクリーンの表示モード切り替えは行いません。
OS の通知やセキュリティ画面などは通常の Windows の動作を優先します。
